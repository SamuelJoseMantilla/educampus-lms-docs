# EduCampus LMS

EduCampus LMS es una solución web académica diseñada para centralizar la gestión institucional, los cursos, usuarios, evaluaciones, calificaciones y reportes académicos.

## Objetivo

Centralizar los procesos académicos de una institución educativa mediante una solución web modular.

## Estado del proyecto

Documentación inicial en construcción.

## Reglas generales del proyecto

1. Todo cambio debe realizarse en una rama independiente.
2. Todo aporte debe ser revisado antes de integrarse.
3. Los mensajes de commit deben ser claros y descriptivos.
4. Los conflictos deben resolverse de forma consciente.
